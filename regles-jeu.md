# Règles Du Jeu

## Histoire

Léo et Mia avancent ensemble dans un labyrinthe.

Leur mission :

- trouver le bon chemin ;
- ouvrir les passages ;
- éviter les pièges ;
- arriver **tous les deux** sur le cristal `💎`.

## Comment gagner un niveau

Pour finir un niveau :

1. il faut comprendre le chemin ;
2. récupérer la clé si besoin ;
3. ouvrir la porte ;
4. rejoindre le cristal ;
5. mettre **Léo et Mia ensemble** sur le cristal.

Si un seul héros arrive au cristal, le niveau n'est pas terminé.

## Les commandes

### Léo

- `← ↑ ↓ →` : avancer
- `Shift droit` ou `Espace` : donner un coup d'épée
- `Alt droit` : utiliser le bouclier

### Mia

- `Z Q S D` : avancer
- `F` : utiliser la magie

### Pause

- `Échap` : mettre le jeu en pause

## À quoi servent les héros

### Léo

Léo est fort.

Il peut :

- ouvrir les portes ;
- utiliser les clés ;
- casser les murs fissurés ;
- détruire les pics avec son épée ;
- battre les monstres ;
- combattre le boss.

Règle très importante :

- **seul Léo peut ouvrir une porte**.

### Mia

Mia est magique.

Elle peut :

- révéler un passage caché ;
- ouvrir un mur bloqué ;
- repousser des monstres ;
- activer certains interrupteurs ;
- aider Léo à continuer.

## Le pouvoir de Mia

Le pouvoir de Mia est puissant, mais limité.

### Règles

- Mia a **1 seule magie** ;
- après l'avoir utilisée, il faut attendre environ **30 secondes** ;
- quand sa magie revient, elle peut l'utiliser à nouveau.

### Très important

Quand Mia ouvre un mur avec sa magie :

- le mur disparaît ;
- il ne revient pas ;
- **Léo peut passer ensuite**.

Il faut donc bien choisir **quand** utiliser la magie.

## Les objets et symboles

### Clé `K`

- sert à ouvrir une porte ;
- elle aide Léo.

### Porte `D`

- bloque le chemin ;
- Léo doit l'ouvrir avec une clé.

### Cristal `C`

- c'est l'arrivée du niveau ;
- les deux héros doivent y aller.

### Portail `P` et `Q`

- `P` est l'entrée ;
- `Q` est la sortie.

Le portail aide surtout quand Léo est coincé ou séparé.

### Mur caché `H`

- il cache un passage ;
- Mia peut le révéler.

### Mur fissuré `*`

- Léo peut le casser.

### Pics `X`

- ils sont dangereux ;
- Léo peut les détruire avec son épée.

### Interrupteur `S`

- il active quelque chose ;
- souvent une grille.

### Grille `G`

- elle bloque le passage ;
- elle s'ouvre quand il faut activer la bonne chose.

### Torche `t`

- aide à mieux voir dans le noir.

### Orbe `o`

- aide à révéler les passages cachés.

## Comment réfléchir dans le jeu

Quand tu ne sais pas quoi faire, pense dans cet ordre :

1. Où est le cristal ?
2. Où est la clé ?
3. Où est la porte ?
4. Est-ce que Mia doit révéler quelque chose ?
5. Est-ce qu'un portail peut aider Léo ?

## Astuce très simple

Souvent, la bonne idée est :

1. **Mia découvre ou ouvre le passage** ;
2. **Léo avance, combat et ouvre la porte** ;
3. **les deux se retrouvent au cristal**.

## Plus on avance, plus c'est difficile

Au début :

- on apprend les bases ;
- on comprend comment Léo et Mia s'aident.

Au milieu :

- il y a plus de pièges ;
- plus de monstres ;
- plus de chemins cachés ;
- parfois du temps à respecter.

À la fin :

- plusieurs règles sont mélangées ;
- il faut aller plus vite ;
- il faut mieux réfléchir ;
- il faut bien utiliser la magie de Mia.

## Indices pour aider sans donner la solution

- "Si tu es bloqué, essaye d'abord Mia."
- "Si une porte te bloque, cherche la clé."
- "Si Léo est séparé, regarde s'il y a un portail."
- "N'utilise pas la magie de Mia trop vite."
- "Le cristal montre souvent la zone finale."
- "Dans les niveaux difficiles, regarde tout le niveau avant d'agir."

## Règle d'or

**Mia ouvre la voie. Léo termine le passage. Les deux gagnent ensemble.**
