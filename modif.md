# Modifications Et Règles Du Jeu

## Vue d'ensemble

Ce document résume :

- les modifications apportées au jeu ;
- les règles de base ;
- les contrôles ;
- le fonctionnement des pouvoirs de Léo et Mia ;
- l'organisation de la progression des niveaux ;
- des indices de lecture pour aider un joueur sans lui donner immédiatement la solution.

Le jeu repose sur une idée simple : **Léo et Mia doivent coopérer pour atteindre ensemble le cristal final**.

## But du jeu

À chaque niveau :

- il faut comprendre le labyrinthe ;
- récupérer les éléments utiles comme la clé, l'orbe ou la torche selon le niveau ;
- ouvrir le chemin final ;
- amener **Léo et Mia ensemble** sur le cristal `💎`.

Un niveau n'est terminé que lorsque **les deux héros** sont sur le cristal.

## Contrôles

### Léo

- `← ↑ ↓ →` : se déplacer
- `Shift droit` ou `Espace` : attaquer avec l'épée
- `Alt droit` : activer le bouclier

### Mia

- `Z Q S D` : se déplacer
- `F` : utiliser la magie

### Divers

- `Échap` : pause / menu

## Fonctionnement des héros

### Léo

Léo est le héros d'action. Il sert à :

- ouvrir les portes ;
- utiliser les clés ;
- casser les murs fissurés ;
- détruire les pics avec l'épée ;
- battre les monstres ;
- affronter le Gardien dans les niveaux de boss ;
- sécuriser la progression jusqu'au cristal.

Règles importantes :

- **Seul Léo peut ouvrir les portes**.
- Quand Léo touche un mur fissuré, il le casse automatiquement.
- Le bouclier peut bloquer les pics et certains ennemis.

### Mia

Mia est le héros de soutien, d'exploration et d'ouverture du chemin. Elle sert à :

- révéler les passages cachés ;
- ouvrir un mur bloquant avec sa magie ;
- repousser ou éliminer certains monstres avec sa magie ;
- activer des interrupteurs ;
- éclairer les niveaux sombres ;
- aider Léo à ne pas rester bloqué.

## Pouvoir de Mia

Le pouvoir de Mia a été modifié.

### Règles actuelles

- Mia n'a **qu'une seule charge de magie**.
- Après utilisation, elle doit attendre environ **30 secondes** pour récupérer sa magie.
- Le temps de récupération est conservé pour limiter l'abus du pouvoir.

### Ce que fait sa magie

Selon le contexte, la magie de Mia peut :

- révéler un passage caché ;
- ouvrir un mur ;
- repousser un monstre ;
- aider à explorer un niveau sombre.

### Modification importante

Avant, les murs ouverts par Mia étaient temporaires.

Maintenant :

- quand Mia ouvre un mur avec `F`, **le mur disparaît définitivement** ;
- cette ouverture reste active pour tout le niveau ;
- cela permet à **Léo de passer ensuite** ;
- cela évite qu'un joueur reste bloqué à cause d'un mur revenu en place.

## Portes de téléportation

Une autre grosse modification a été ajoutée : les **portails de téléportation**.

### Principe

- `P` = entrée du portail
- `Q` = sortie du portail

### Rôle dans le gameplay

Les portails ont été intégrés dans **tous les niveaux** pour éviter qu'un parcours bloque définitivement Léo.

Ils servent à :

- débloquer une situation de séparation ;
- faire rejoindre plus vite la zone finale ;
- garder la logique de coopération sans forcer un level design trop punitif.

### Règle d'usage

- quand un personnage marche sur `P`, il est téléporté vers `Q` ;
- dans la pratique, ces portails servent surtout à **débloquer Léo** et à le rapprocher du cristal ou de Mia.

## Objets et éléments du décor

### Clé `K`

- permet à Léo d'ouvrir une porte ;
- si Mia ramasse une clé, elle est quand même donnée au stock de Léo.

### Porte `D`

- ne peut être ouverte que par Léo ;
- consomme une clé.

### Cristal `C`

- objectif de fin du niveau ;
- les deux héros doivent s'y retrouver.

### Interrupteur `S`

- active une grille ;
- Mia est souvent utilisée pour l'activer.

### Grille `G`

- s'ouvre quand l'interrupteur ou la condition du niveau est validée ;
- dans certains niveaux, son ouverture est temporaire.

### Mur caché `H`

- visible ou révélable grâce à Mia ;
- sert à cacher le bon chemin.

### Mur fissuré `*`

- cassable par Léo ;
- sert à bloquer le passage jusqu'à l'intervention de Léo.

### Pics `X`

- dangereux ;
- peuvent être détruits par Léo avec son épée.

### Orbe `o`

- révèle les passages cachés du niveau.

### Torche `t`

- aide dans les niveaux sombres.

### Plaques `1` et `2`

- demandent souvent que Léo et Mia coopèrent en même temps.

### Symboles `a`, `b`, `c`

- imposent un ordre d'activation dans certains niveaux.

### Boss `@`

- présent dans certains niveaux avancés ;
- Léo doit le vaincre.

## Progression de la difficulté

Le jeu est construit pour devenir plus difficile au fil des niveaux.

### Début du jeu

Les premiers niveaux apprennent :

- la complémentarité entre Léo et Mia ;
- la clé et la porte ;
- les passages cachés ;
- le mur fissuré ;
- le portail de déblocage.

### Milieu du jeu

Les niveaux intermédiaires ajoutent :

- les interrupteurs et grilles ;
- les monstres ;
- les niveaux sombres ;
- les symboles dans un ordre précis ;
- la pression du temps ;
- les choix de trajectoire.

### Fin du jeu et bonus

Les derniers niveaux cumulent plusieurs mécaniques :

- monstres ;
- murs magiques ;
- grilles temporisées ;
- ordre de symboles ;
- clé + porte ;
- boss ;
- besoin de coordination rapide ;
- punition plus forte en cas d'erreur.

En résumé :

- **plus on monte en niveau, plus il faut lire le niveau avant d'agir** ;
- **les erreurs de timing coûtent plus cher** ;
- **la coopération devient plus technique**.

## Lecture du jeu par familles de niveaux

### Niveaux 1 à 4

Objectif pédagogique :

- comprendre la logique Léo/Mia ;
- apprendre que Mia ouvre l'information ou le passage ;
- apprendre que Léo termine l'action.

Indice de jeu :

- si une porte bloque, demande-toi d'abord où est la clé ;
- si le chemin semble fermé, teste Mia avant de forcer avec Léo.

### Niveaux 5 à 8

Objectif pédagogique :

- apprendre la coordination plus stricte ;
- gérer les plaques, monstres, passages cachés, obscurité.

Indice de jeu :

- Mia prépare le terrain ;
- Léo sécurise et termine.

### Niveaux 9 à 10

Objectif pédagogique :

- introduire la pression du temps ;
- demander des décisions plus rapides ;
- faire comprendre que l'ordre d'action compte autant que l'action elle-même.

Indice de jeu :

- ne partez pas chacun au hasard ;
- définissez qui ouvre, qui combat, qui déclenche, puis exécutez.

### Niveaux bonus 11 à 15

Objectif pédagogique :

- mélanger toutes les mécaniques ;
- augmenter la punition ;
- demander une lecture complète de la carte.

Indice de jeu :

- observer avant d'agir ;
- repérer le cristal, la porte, la clé, puis seulement chercher le chemin ;
- utiliser Mia avec parcimonie car sa recharge est longue.

## Résumé des modifications techniques déjà faites

### Modifications de level design

- ajout de portails de téléportation dans tous les niveaux ;
- adaptation des parcours pour éviter que Léo reste bloqué ;
- conservation d'une logique coopérative jusqu'au cristal.

### Modifications de pouvoir de Mia

- le mur ouvert par Mia reste ouvert définitivement ;
- ce mur peut ensuite être traversé par Léo ;
- Mia n'a plus 3 charges ;
- Mia n'a plus qu'**une seule charge** ;
- le temps de récupération a été augmenté à **environ 30 secondes**.

### Modifications de lisibilité

- les indices de niveau ont été enrichis ;
- les objectifs affichés guident mieux le joueur ;
- la progression est plus claire : révéler, ouvrir, combattre, rejoindre.

## Règles simples à donner à un joueur

Version courte :

1. Mia découvre ou ouvre le chemin.
2. Léo récupère la clé, combat et ouvre la porte.
3. Si Léo est séparé, cherche le portail.
4. Utilise la magie de Mia avec prudence : une seule charge, recharge longue.
5. Les deux héros doivent finir ensemble sur le cristal.

## Idées d'indices à afficher dans le jeu

### Indices généraux

- "Si tu ne vois pas le chemin, essaye Mia."
- "Si une porte bloque, Léo doit sûrement trouver une clé."
- "Si Léo semble coincé, observe les portails."
- "La magie de Mia est rare : utilise-la au bon moment."
- "Un chemin caché est parfois plus important qu'un combat."

### Indices pour les niveaux avancés

- "Regarde d'abord l'emplacement du cristal."
- "Le bon ordre d'action vaut mieux que la vitesse."
- "Dans les niveaux sombres, la lumière sert à lire le niveau."
- "Quand un boss apparaît, Léo doit finir le travail."

## Conclusion

Le jeu fonctionne comme un puzzle coopératif d'action.

La logique générale est :

- **Mia débloque ou révèle** ;
- **Léo agit et sécurise** ;
- **les deux se rejoignent pour finir**.

Avec les dernières modifications, le jeu reste exigeant, mais il évite les blocages injustes grâce :

- aux portails ;
- aux murs ouverts définitivement ;
- à une magie de Mia plus rare mais plus stratégique.
